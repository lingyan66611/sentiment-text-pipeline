# 多源舆情文本采集与清洗（预制菜进校园）

## 项目简介
自然语言处理课程项目。覆盖微博、知乎、小红书、B 站四平台，采集、清洗、去重后产出 7 类结构化语料，用于文本时序分析。

## 采集
collect_weibo.py / collect_weibo_comments.py / collect_zhihu.py / collect_xiaohongshu.py / collect_bilibili.py
- 关键词扩展：jieba 分词加候选词表扩充
- 稳定性：随机停顿、UA 轮换、断点续采（checkpoint 记录已采页码与时间）
- 登录凭证不入库，本地运行需自行登录各平台

## 清洗与去重
- 解析各平台 HTML/JSON 混合响应，按平台、发布时间、正文、互动量做字段映射
- 朴素贝叶斯伪标签剔除与主题无关文本
- SimHash 近似去重，35 万条原始文本保留 60,329 条有效语料

## 产出
7 类结构化数据集（CSV/JSON），字段定义见预处理脚本内的字段映射；原始语料与中间文件体积大，未入库。

## 分工
采集与预处理（本项目代码范围）；下游分析与建模由组内另一位同学完成。
